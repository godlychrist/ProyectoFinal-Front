# 🎨 Documentación Frontend (Nuxt 4 PWA)

Bienvenido a la carpeta de documentación de la interfaz de usuario.

## 📄 Estructura de la aplicación
* **Framework**: Nuxt 4 + Vue 3
* **PWA**: Módulo `@vite-pwa/nuxt` para soporte offline, manifest e íconos instalables.
* **Estilos**: CSS Vanilla / Módulos de componentes.

## 🚀 PWA (Progressive Web App)
La aplicación cuenta con configuración de Manifest y Service Worker autogenerado con Workbox (`generateSW`), garantizando la instalabilidad en sistemas móviles y de escritorio.
